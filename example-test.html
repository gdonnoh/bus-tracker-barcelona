🚌 Esempi di Test API TMB i-bus

1. Ottenere tempi di arrivo per una fermata

Endpoint per ottenere i prossimi arrivi alla fermata specificata:

GET https://api.tmb.cat/v1/ibus/stops/{stopCode}

Parametri:
  • app_id - Il tuo APP_ID
  • app_key - La tua APP_KEY

Esempio:

https://api.tmb.cat/v1/ibus/stops/3258?app_id=YOUR_APP_ID&app_key=YOUR_APP_KEY
Risposta esempio (JSON): 
{
  "status": "success",
  "data": {
    "ibus": [
      {
        "destination": "Horta",
        "line": "V25",
        "routeId": "2250",
        "t-in-min": 0,
        "t-in-s": 31,
        "text-ca": "imminent"
      },
      {
        "destination": "Plaça Catalunya",
        "line": "V25",
        "routeId": "2251",
        "t-in-min": 5,
        "t-in-s": 0,
        "text-ca": "5 min"
      }
    ]
  }
}

Nota: I campi principali sono:

  • t-in-min: Minuti fino all'arrivo
  • t-in-s: Secondi fino all'arrivo (quando molto vicino)
  • text-ca: Testo descrittivo in catalano (es: "imminent", "5 min")
  • line: Numero della linea bus
  • destination: Destinazione del bus

2. Test con cURL

Puoi testare l'API direttamente dalla riga di comando:

curl "https://api.tmb.cat/v1/ibus/stops/3258?app_id=YOUR_APP_ID&app_key=YOUR_APP_KEY"

3. Test con JavaScript (fetch)

Esempio di chiamata API da JavaScript:

const stopCode = '3258';
const appId = 'YOUR_APP_ID';
const appKey = 'YOUR_APP_KEY';

const url = `https://api.tmb.cat/v1/ibus/stops/${stopCode}?app_id=${appId}&app_key=${appKey}`;

fetch(url)
  .then(response => response.json())
  .then(data => {
    console.log('Arrivi:', data);
    // Processa i dati
    if (data.data && data.data.ibus) {
      data.data.ibus.forEach(arrival => {
        console.log(`Linea ${arrival.line}: arrivo tra ${arrival.estimateArrive} minuti`);
      });
    }
  })
  .catch(error => {
    console.error('Errore:', error);
  });

4. Codici Fermata Comuni a Barcellona

Alcuni codici fermata per testare (verifica sulla mappa TMB):

  • 3258 - Esempio comune
  • 3259 - Esempio comune
  • Altri codici possono essere trovati usando l'app TMB ufficiale o la mappa online

Nota: I codici fermata possono cambiare. Usa l'app TMB ufficiale per trovare codici aggiornati.

5. Come Trovare Codici Fermata

  1. Usa l'app TMB ufficiale su smartphone
  2. Vai su una fermata e controlla il codice visualizzato
  3. Oppure visita tmb.cat e usa la mappa interattiva
  4. Il codice fermata è solitamente un numero di 4-5 cifre

6. Possibili Errori API

  • 401 Unauthorized: Credenziali API non valide o mancanti
  • 404 Not Found: Fermata non trovata (codice errato)
  • 429 Too Many Requests: Troppe richieste - rispetta i rate limits
  • 500 Server Error: Errore lato server TMB

7. Prossimi Passi

  1. Ottieni le credenziali API da developer.tmb.cat
  2. Inserisci le credenziali in config.js
  3. Apri index.html nel browser
  4. Testa con una fermata reale usando il codice
  5. Testa la geolocalizzazione (potrebbe richiedere HTTPS in produzione)
⚠️ Nota Importante:

Per utilizzare la geolocalizzazione in produzione, l'applicazione deve essere servita tramite HTTPS. Per test locali, puoi usare un server locale come python -m http.server o npx http-server.
